显示设置
摘要字段
指定要在摘要部分显示的字段名称，用逗号分隔。要包含 CivitAI 元数据中的字段，请添加 "civitai." 前缀（例如 "civitai.trainedWords"）。要包含自定义字段，请添加 "custom." 前缀（例如 "custom.training_time"）。
自定义摘要模板
此部分定义用于自定义摘要布局的模板，格式为 HTML。要显示的字段必须定义在 {{}} 中（例如：{{ss_output_name}}）。要包含文件元数据字段，直接指定字段名称即可。要包含 CivitAI 元数据中的字段，请添加 "civitai." 前缀（例如 "civitai.trainedWords"）。要包含自定义字段，请添加 "custom." 前缀（例如 "custom.training_time"）。
元数据编辑器字段
指定要在元数据编辑器简单视图中显示的字段名称，用逗号分隔。
自定义字段
此部分定义可在摘要部分显示的自定义字段列表。计算定义为 JavaScript 表达式。计算中可使用以下数据：Safetensors 文件元数据（fileMetadata）、CivitAI 资源信息（civitaiMetadata）以及先前定义的自定义字段（customMetadata）。请注意，自定义字段按列表中定义的顺序创建，这意味着只有在前面行中已定义的自定义字段才能在计算中使用。

HTTP 代理
由于网站安全限制，Arc En Ciel 资源查询需要此设置。启用后，对 Arc En Ciel 的请求将通过代理 URL 转发。


本地 HTTP 代理（可选）
或者，也可以使用以下最小 Python 脚本在本地托管代理 Web 服务器。要在本地运行代理，请下载/复制以下 'proxy.py' Python 脚本，将文件放在与此应用程序的 .html 文件相同的文件夹中，并使用以下命令执行脚本 python proxy.py --port 8008。运行该命令将在 http://localhost:8008 启动应用程序。将上面的"代理 URL"设置替换为 http://localhost:8008/?url= 即可使用本地实例。

proxy.py - 下载
import http.server
import socketserver
import webbrowser
import argparse
from urllib.parse import urlparse, parse_qs, unquote
import urllib.request
import urllib.error
import os

parser = argparse.ArgumentParser()
parser.add_argument('--port', type=int, default=8008)
parser.add_argument('--html_file', type=str, default="index.html")
args = parser.parse_args()

PORT = args.port
HTML_FILE = args.html_file

if not os.path.exists(HTML_FILE):
    raise FileNotFoundError(f"{HTML_FILE} not found")

class CORSRequestHandler(http.server.SimpleHTTPRequestHandler):
    def end_headers(self):
        self.send_header('Access-Control-Allow-Origin', '*')
        self.send_header('Access-Control-Allow-Methods', 'GET,POST,OPTIONS')
        self.send_header('Access-Control-Allow-Headers', 'X-Requested-With, Content-Type')
        super().end_headers()

    def do_GET(self):
        parsed = urlparse(self.path)
        query = parse_qs(parsed.query)
        target = query.get('url', [None])[0]
        if target:
            try:
                print(f'Fetching: {target}')
                req = urllib.request.Request(
                    unquote(target),
                    headers={ 'User-Agent': 'Mozilla/5.0', 'Accept': '*/*' }
                )
                with urllib.request.urlopen(req) as resp:
                    self.send_response(resp.status)
                    for k, v in resp.getheaders():
                        self.send_header(k, v)
                    self.end_headers()
                    self.wfile.write(resp.read())
            except urllib.error.HTTPError as e:
                self.send_response(e.code)
                for k, v in e.headers.items():
                    self.send_header(k, v)
                self.end_headers()
                self.wfile.write(e.read())
            except Exception as e:
                self.send_response(500)
                self.end_headers()
                self.wfile.write(str(e).encode())
        else:
            super().do_GET()

os.chdir(os.path.dirname(os.path.abspath(HTML_FILE)))
with socketserver.TCPServer(('', PORT), CORSRequestHandler) as httpd:
    print(f"Serving on http://localhost:{PORT}")
    webbrowser.open(f"http://localhost:{PORT}/{HTML_FILE}")
    httpd.serve_forever()
